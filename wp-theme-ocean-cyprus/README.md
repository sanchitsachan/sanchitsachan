# Ocean Cyprus Restaurant — Elementor Theme

A clean, Elementor-ready WordPress theme tailored to the provided seaside restaurant design.

## Install
1. Zip the theme folder (`wp-theme-ocean-cyprus`) and upload in WordPress: Appearance → Themes → Add New → Upload.
2. Activate the theme.
3. Install the free plugin: Elementor.

## Menus
- Go to Appearance → Menus and assign a menu to `Primary Menu` and optionally `Footer Menu`.

## Homepage
- The provided `front-page.php` renders a homepage matching the screenshot.
- Replace placeholder images in `assets/images/` with your own (keep the same filenames or update the paths in `front-page.php`).

## Elementor Usage
- Create additional pages using the template: `Elementor Full Width` (Page → Template).
- You can redesign the homepage in Elementor too: create a new page, set Template to `Elementor Full Width`, and set it as the Homepage in Settings → Reading.

## Colors & Fonts
- Colors are defined in `style.css` in the `:root` variables.
- Fonts loaded: Inter (UI) and Playfair Display (headings).

## Contact Form
- The contact section ships with a simple HTML form placeholder.
- Recommended: Install Contact Form 7 or WPForms and replace the form with a shortcode.

## Images
- Add these files (or your own) to `assets/images/`:
  - `hero.jpg`, `side.jpg`, `gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg`

## Customize Logo
- Appearance → Customize → Site Identity → Upload Logo.

## Support
This theme is lightweight and Elementor-compatible. For deeper customizations, build sections with Elementor using the Full Width template.
