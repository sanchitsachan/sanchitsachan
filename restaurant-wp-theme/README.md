# Seaside Restaurant – WordPress Theme

Install steps:

1. Zip the theme folder `restaurant-wp-theme` and upload to WordPress (Appearance → Themes → Add New → Upload Theme), or copy the folder into `wp-content/themes/`.
2. Activate the theme.
3. Create a page called “Home” and assign it as the static homepage (Settings → Reading → Your homepage displays).
4. Set a featured image on the Home page for the hero background.
5. Go to Appearance → Customize → Contact & Hours to set phone, address, hours, reservation URL, and map embed.
6. Create a menu and assign it to “Primary Menu”. Optionally add a “Footer Menu”.

Optional:
- Install Contact Form 7 and replace the placeholder form in the Home page section with your shortcode.
- Replace images in `assets/img/` with your own.
